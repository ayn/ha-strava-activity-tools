# Security reports

Use GitHub private vulnerability reporting for security issues. Do not include
OAuth tokens, private activity URLs, routes or production configuration in public
issues. Ordinary bugs and feature requests belong in GitHub Issues.

Preview mode blocks writes by default. Only enable writes after reviewing the
selected account, proposed changes and other automations updating the same fields.
The Strava API does not provide atomic conditional activity writes.

The existing Strava connection owns credentials. Provider policies and HA host
access controls apply separately from this project's code license.
